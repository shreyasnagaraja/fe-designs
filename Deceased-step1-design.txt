### 4A. Read-Only Display Fields (use existing InfoField/LabelValue component)

| Field | Label text | Value source | Section |
|-------|-----------|--------------|---------|
| name | "Name:" | `customer.fullName` | Official details |

### 4B. Editable / Input Fields

| Field | Component | Type | Required | Validation | Default/Preload |

| `executorCountry` | Select/Dropdown | country list | NO | — | "NETHERLANDS" |

| `executorForAttentionOf` | TextInput | string | NO | max 100 chars | from API or empty |
| `executorCareOf` | TextInput | string | NO | max 100 chars | from API or empty |

**Postcode lookup behavior:**
1. User enters postcode (format: `1234 AB`) and house number
2. User clicks 🔍 icon
3. API call: resolve postcode → returns street name + city
4. Display resolved address as read-only text directly below the postcode+housenumber row
5. If lookup fails: show inline error "Address not found"

## 8. VALIDATION RULES

```typescript
// Required field validation (Next button guard)
const isFormValid = computed(() => {
  return (
    !!formState.dateOfDecease &&         // must have value
    isValidDate(formState.dateOfDecease) && // must be valid date
    !!formState.formOfAddress             // must be selected
  );
});

// Date of decease: DD-MM-YYYY format, not in future
// Form of address: must be one of the 4 enum values
// Postcode: regex /^\d{4}\s?[A-Z]{2}$/i (optional field but if entered, validate format)
// House number: numeric only (optional)
```

## 9. PINIA STORE SHAPE

```typescript
// store/slsDeceasedStore.ts
interface SlsDeceasedState {
  // Customer read-only data (fetched once on mount)
  customer: {
    fullName: string;
    address: {
      street: string;
      postalCode: string;
      city: string;
      country: string;
    };
    dateOfBirth: string;           // ISO date string
  } | null;

  // SLS data from GET /sls/{customerId}
  currentSlsData: {
    specialLegalStatus: string;    // e.g. "DECEASED"
    dateOfDecease: string | null;  // ISO date
    formOfAddress: FormOfAddressEnum | null;
    executorAddress: ExecutorAddress | null;
  } | null;

  // Editable form state (mirrors what will be PUT)
  formState: {
    dateOfDecease: string | null;
    formOfAddress: FormOfAddressEnum | null;
    executorCountry: string;
    executorPostcode: string;
    executorHouseNumber: string;
    executorForAttentionOf: string;
    executorCareOf: string;
  };

  // Postcode lookup
  resolvedAddress: string | null;
  isPostcodeLookupLoading: boolean;

  // UI state
  isLoading: boolean;
  isSaving: boolean;
  errorMessage: string | null;
}

type FormOfAddressEnum = 'ERVEN_VAN' | 'ERVEN_VAN_MEVROUW' | 'BOEDEL_VAN' | 'BOEDEL_VAN_MEVROUW';
```
